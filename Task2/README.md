## 2.2 Описание доменов
| Domain | Description |
| --- | --- |
| `Медицинские услуги` | **Данные**: </br>- Медицинские карты </br>- Медицинские анализы </br>- Медицинские назначения </br>**Преимущества выделения в отдельный домен**: </br>- Независимое бизнес направление </br>- Независимая команда разработки и развития </br>- Независимые эксперты предметной области </br>- Независимость развития бизнес-логики </br>- Упрощает реализацию разграничения доступа к медицинским данным </br>- Изоляция медицинских данных от других доменных сервисов </br>- Снижение операционных затрат на поддержку специфичных для домена средств и стандартов защиты данных |
| `Банковские услуги` | **Данные**: </br>- Счета </br>- Кредиты </br>- Истории финансовых операций </br>**Преимущества выделения в отдельный домен**: </br>- Независимое бизнес направление </br>- Независимая команда разработки и развития </br>- Независимые эксперты предметной области </br>- Независимость развития бизнес-логики </br>- Упрощает реализацию разграничения доступа к данным по финансовым операциям </br>- Изоляция финансвых данных от других доменных сервисов </br>- Снижение операционных затрат на поддержку специфичных для домена средств и стандартов защиты данных (PCI DSS) |
| `Администрирование и управление` | **Данные**: </br>- Графики приемов и посещений </br>- Учет оборудования и инвентаря </br>- Документооборот </br>**Преимущества выделения в отдельный домен**: </br>- Независимое бизнес направление </br>- Независимость развития бизнес-логики </br>- Возможность использования готовых коробочных решений </br>- Не приносят конкурентного преимущества </br>- Возможность вынесения на аутсорсинг |
| `Физические лица` | **Данные**: </br>- Форма регистрации </br>- Продуктовый профиль </br>**Преимущества выделения в отдельный домен**: </br>- Пользователь имеет единый доступ ко всем продуктам компании </br>- Возможность развития бизнес платформы </br>- Снижение операционных затрат на поддержку специфичных для домена средств и стандартов защиты данных (ФЗ-152) |
| `Управление данными` | **Преимущества выделения в отдельный домен**: </br>- Возможность развития в готовый "дата-продукт" (ML-service) </br>- Реализация BI self-service </br>- Данные семантически сгруппированы и доступны для анализа экспертам предметной области </br>- Независимая команда разработки и развития </br>- Независимые эксперты предметной области (управление и поддержка бизнес модели данных) |
