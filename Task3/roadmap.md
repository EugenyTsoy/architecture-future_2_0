**Этапы**:

Этап 1 (Q3 2025) — Базовое разделение и стандартизация

- Цель: отделить домены (депозиты, колл-центр, клиенты) и вынести их в отдельные сервисы.

- Технологии: FastAPI, PostgreSQL, Docker.

- Результаты: минимальный API Gateway, авторизация через Keycloak, контейнеризация сервисов.

- Команды: Core Dev Team.

- Ресурсы: 2 backend, 1 frontend, DevOps.

Этап 2 (Q4 2025) — CI/CD и автоматизация

- Цель: настроить GitLab CI/CD, добавить автоматическое тестирование и деплой.

- Технологии: Kubernetes, Helm, Minikube → кластер в облаке.

- Результаты: прозрачные пайплайны, staging/prod окружения.

- Команды: DevOps + QA Automation.

Этап 3 (Q1 2026) — Интеграции и Event-Driven

- Цель: избавиться от файловых интеграций, перейти на Kafka для обмена событиями.

- Технологии: Kafka, Redis (для кэша).

- Результаты: независимость доменов, быстрая синхронизация, меньше ошибок при обмене.

- Команды: Integration Team.

Этап 4 (Q2 2026) — Advanced Observability

- Цель: внедрить централизованный сбор логов и мониторинг.

- Технологии: ElasticSearch, Grafana, Prometheus.

- Результаты: SLA по доступности, раннее обнаружение проблем.

- Команды: SRE Team.
